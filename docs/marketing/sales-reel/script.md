## 目標受眾
保險、房仲、汽車、貸款、B2B 方案等**靠信任成交的業務**。
他們不缺說服力，缺的是「客戶私下查你的時候，查得到東西」。

## 敘事策略（為什麼這樣排）
1. **開場是每個業務都聽過的那句話：「我再考慮看看。」** 不用解釋，業務一看就懂那是什麼處境。
2. **把「考慮」翻譯成「他去搜尋你了」。** 這是業務最少想到、但最真實的一步：客戶不是在考慮，是在查你。
3. **查不到＝不敢買。** 痛點只講這一個，然後用「名片會被丟掉、LINE 會被洗掉、只有網站 24 小時都在」三連發，讓網站的價值變成一個對比，不是一個功能。
4. **轉折落在「信任」兩個字。** 業務賣的從來不是產品，是信任；形象官網是信任的載體。
5. **功能只講業務在意的三件事**：一個連結講清楚你是誰／成交與好評當證據／客戶看完直接留名單。
6. **真實案例**：JeanToGo（外送平台合作顧問的個人業務網站）的正式站畫面，在手機裡實際捲動。
   這是我們真的做過、已上線的業務網站，不是示意圖；客戶已同意用於廣告。
7. **價格放在證據之後**，最後用開場那句話收尾：「下次客戶說再考慮看看，讓他先看到你的網站。」

## 怎麼重新產出

```
cd build
pip install edge-tts numpy scipy        # 第一次才需要
npm i playwright                        # 第一次才需要

python3 make-vo.py        # 錄旁白，並依旁白長度產生 timeline.json / timeline.js
node    render.js --sfx   # 從 reel.html 讀出音效時間表 → sfx.json
python3 make-bgm.py       # 合成配樂 bgm.wav 與音效 sfx.wav
python3 make-audio.py     # 旁白＋配樂＋音效 → audio.m4a（-14 LUFS）
node    render.js         # 逐幀截圖餵給 ffmpeg → ../avalo-sales-reel.mp4
```

換聲音：`VOICE=zh-TW-HsiaoChenNeural python3 make-vo.py`；調語速：`RATE=+12%`。
配樂太大聲或太小聲：`MUSIC_LUFS=-26 python3 make-audio.py`（數字愈小配樂愈小聲）。
檢查畫面：`node render.js --shots 3,8.5,19.8` 會把指定秒數存到 `build/frames/`。
