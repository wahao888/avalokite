# 阿瓦羅品牌動畫 — 3D 卡通劇情短片（9:16／約 63 秒）

成品：`avalo-brand-reel.mp4`（1080×1920、30fps、H.264＋AAC，旁白＋字幕＋配樂）
可播放原稿：`reel.html`（要透過 `node build/serve.js` 開，見最下方）

## 故事

一座浮在雲上的小島，島上只有阿福的一間小店。東西很好，但沒有人知道——
畫面是灰的，招牌是歪的，只有風滾草滾過去。

直到阿瓦羅的熱氣球降下來。三位戴著工程帽的團隊成員跳出籃子，天色從陰天變成日出，
顏色回到畫面裡。接下來每一項服務都是島上「長出來」的一樣東西，鏡頭一路繞著島走，

## 敘事上的幾個決定

- **主角是客戶，不是我們。** 阿瓦羅在片子裡是「一組人」（三位團隊成員＋一顆有標誌的熱氣球），
  沒有任何一個角色代表創辦人或工程師——這是品牌語調的要求，也讓「一個團隊做到好」那句有畫面可以對。
- **每項服務只有一個動作。** 六項服務各五秒，再多就會變成功能清單。每一幕上方只有編號和服務名。
- **沒有寫不出處的承諾。** 搜尋那一幕的旁白是「找得到你／讀得懂你」，不是「排第一」；
  畫面上的「第 1 筆」是搜尋自己店名的結果，不是關鍵字排名。
- **顏色本身是劇情。** 開場飽和度壓到四成，熱氣球出現的那一刻才放開。

## 怎麼做的

- **3D**：three.js（專案本來就有的相依套件），所有東西都是程式蓋出來的幾何，沒有外部模型或貼圖檔。
  角色是兩頭身、沒有手臂的造型，表情靠眼睛與嘴角，動作靠跳、舉手、歪頭。
- **每一格都是時間的純函數**（`src/story.js`）：沒有累加的狀態，所以可以跳到任何一秒渲染那一格，
  逐幀輸出不會走樣。
- **旁白**：Microsoft Edge 線上神經語音 `zh-TW-HsiaoChenNeural`，語速 +3%。
- **配樂**：程式合成、112 BPM、C–Am–F–G。開場小調；熱氣球出現時 F→G 往上推；
  半夜那一幕抽掉鼓變成搖籃曲；大合照加弦樂與口哨。
- **音效**：時間點寫在 `src/story.js`，跟畫面動作、火花是同一組數字。
- **字幕**：已燒進畫面。**上傳時請關掉 IG 的自動字幕**。

## 檔案

```
reel.html          疊在 3D 上的東西：服務標題、字幕、片尾
src/kit.js         材質、幾何、緩動、貼圖文字、角色（造型與擺姿勢）
src/world.js       把島、小店、熱氣球、六項服務的道具蓋出來
src/story.js       劇本：鏡頭、天色、走位、每個道具什麼時候怎麼動、音效時間表
src/main.js        渲染器、燈光，以及把 3D 和 HTML 疊層綁到同一條時間軸
build/             旁白、配樂、混音、逐幀渲染
```

## 怎麼重新產出

```
cd build
pip install edge-tts numpy scipy        # 第一次才需要
npm i playwright                        # 第一次才需要

python3 make-vo.py        # 錄旁白，並依旁白長度產生 timeline.json / timeline.js
node    render.js --sfx   # 從劇本讀出音效時間表 → sfx.json
python3 make-bgm.py       # 合成配樂 bgm.wav 與音效 sfx.wav
python3 make-audio.py     # 旁白＋配樂＋音效 → audio.m4a（-14 LUFS）
node    render.js         # 逐幀截圖餵給 ffmpeg → ../avalo-brand-reel.mp4（約 5–10 分鐘）
```

預覽：`node build/serve.js` 之後開 http://localhost:4173/reel.html。
不能直接雙擊 `reel.html`——three.js 是 ES module，瀏覽器不讓 `file://` 的頁面載入模組。

檢查畫面：`node render.js --shots 4.4,14.3,25.9` 會把指定秒數存到 `build/frames/`。

渲染會用顯示卡（`--use-angle=metal`）。沒有這個旗標時無頭瀏覽器會退回軟體算圖，
帶陰影的 3D 場景一格要好幾秒。

**寫死在畫面裡的資料**：片尾的網址與 LINE ID（`reel.html`）、服務名稱（`reel.html` 的六個標題）。
服務項目有增減時，`make-vo.py` 的 `SCENES`、`story.js` 的對應段落與這六個標題要一起改。
