# 零元啟動・限時開放 — 短影音腳本（9:16／約 38 秒）

對應可播放成品：`docs/marketing/promo-reel.html`
檔期參數改這裡：`promo-reel.html` 開頭的 `CONFIG`（名額、已認購、截止日）

## 目標受眾
微型企業主、個人品牌、靠信任成交的業務（保險／房仲／貸款／直銷）。
他們的痛點不是「沒有網站」，是**客戶不信任他**，以及**名片發出去就斷線**。

## 敘事策略（為什麼這樣排）
1. **前 2 秒必須是痛，不是品牌。** 社群影音的留存全押在第一秒，所以開場不放 logo、不放「我們是誰」，直接丟一句客戶真的問過他的話：「你們公司有網站嗎？」
2. **先賣結果，再賣功能。** Hero Banner 不講「動態視覺」，講「3 秒決定他要不要聽你說完」；表單不講「後台」，講「他留下電話，你 24 小時內回得到」。
3. **價格放在價值之後。** 先讓他想要，再把 39,000 劃掉變 0 元，落差才有力量。
4. **先解除風險，再催促。** 「網站上線、你點頭，月費才開始跑」擺在稀缺之前——人只有在不怕被騙之後，才會怕買不到。
5. **稀缺要具體可數。** 不寫「限量」，寫「只開 5 席、已滿 3 席、11/30 截止」，螢幕上看得到席位被點掉。

## 旁白稿（已錄製，見 build/make-vo.py）
每一句都以「唸得完且不趕」為上限反推長度——寫得下的字數比想講的話少很多，
所以旁白只補畫面沒說的，不複誦字幕。

| 進場 | 稿子 |
|---|---|
| 0.35s | 你們公司有網站嗎？ |
| 2.95s | 名片沒人記得，網路上也查不到你。 |
| 7.20s | 阿瓦羅幫你做一支會成交的形象官網。 |
| 13.00s | Google 搜得到你，客戶的聯絡方式自動進後台。 |
| 19.40s | 建置費三萬九，這一檔零元。月費兩千全包。 |
| 24.60s | 而且網站上線、你點頭之後，月費才開始跑。 |
| 29.80s | 本檔只開五席，十一月三十號截止。 |
| 35.00s | 現在就上阿瓦羅官網，鎖定名額。 |

**目前是 macOS 內建的 Meijia（美佳）語音。** 系統裡其他 zh-TW 語音（Sandy、Reed、Eddy…）
只列在清單上、檔案沒下載，`say` 會產出 0.016 秒的空檔。要換更自然的聲音有兩條路：
到「系統設定 → 輔助使用 → 朗讀內容 → 系統語音 → 管理語音」下載，或直接找真人配音——
兩種都只要重跑 `build/make-vo.py` 之後的步驟。

**配音指示**：不要熱血業配腔。要沉穩、低速、每句之間留半拍，像顧問在講給你聽，
才接得上品牌的大公司定位。

## 音樂與剪輯
- 曲風：低音 pulse ＋ 乾淨鋼琴／弦樂，BPM 90–100。第 5 幕（價格）踩一個重拍，第 7 幕（席位）用票閘「嗒」聲點掉席位。
- 轉場：只用淡入與位移，不要滑動特效、不要光斑。
- 字幕：畫面上已燒進字，社群平台的自動字幕請關掉以免重疊。

## 怎麼重新產出影片檔

四個步驟都在 `build/`，依序跑完會得到 `promo-reel.mp4`（1080×1920、30fps、H.264＋AAC）。

```
python3 build/make-vo.py      # say 產旁白，並自動把每句壓進該幕的長度
python3 build/make-bgm.py     # 合成背景襯底，和弦切換點對齊八幕
python3 build/make-audio.py   # 旁白定位＋響度正規化＋背景閃避，輸出 audio.m4a
node    build/render.js       # 逐幀截圖餵給 ffmpeg，混上 audio.m4a
```

**為什麼是逐幀而不是螢幕錄影**：`render.js` 把動畫 `seek()` 到 `t = n/30` 再截圖，
每一幀都精準，機器跑多慢都不會掉幀；即時錄影（包含 Playwright 內建的錄影功能）
會掉幀，而且 Playwright 自帶的 ffmpeg 是 `--disable-everything` 編譯的，
**只有 VP8/WebM、沒有任何音訊編碼器**，做不出帶聲音的 mp4。

需要的工具：`brew install ffmpeg`，以及 `npm i playwright`（瀏覽器本體會沿用
`~/Library/Caches/ms-playwright` 的快取）。

**背景音樂是程式合成的**，不是現成曲子——社群平台的版權偵測會把來路不明的配樂
靜音或限流。要換成授權音樂，把檔案換成 `bgm.wav` 再重跑 `make-audio.py` 即可。
