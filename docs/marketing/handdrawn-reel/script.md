# 阿瓦羅手繪風廣告 — 老闆的待辦清單（9:16／約 57 秒）

成品：`avalo-handdrawn-reel.mp4`（1080×1920、30fps、H.264＋AAC，旁白＋字幕＋配樂）
可播放原稿：`reel.html`（瀏覽器直接開）

## 概念

一本橫線筆記本。老闆在上面寫「開店待辦」，愈寫愈長：做官網、接訂單收款、回 LINE 訊息、
做報表跑流程、讓客人找得到、顧網站——每一件都等著他。

然後一句「這些都可以交給阿瓦羅」。接下來每一項被綠色麥克筆打勾、劃掉，旁邊畫出一張塗鴉。
最後整張清單都劃完了，老闆端著咖啡在笑。

這支跟 3D 那支講的是同一組服務，但角度不同：3D 那支是「我們幫你蓋了什麼」，
這支是「你手上少了什麼事」。清單人人都寫過，所以不用解釋。

## 手繪感是怎麼做出來的

全部是程式畫的，沒有任何圖檔。四件事加起來才像手畫：

1. **線不準**。每條線的端點都有幾個像素的誤差、中間有一點弓，而且同一條線描兩次（`polyD`）。
   圓是用十幾個半徑忽大忽小的點連起來的，收尾會多畫一小段蓋過起點（`ellPts`）。
2. **線是「畫」出來的**。每一筆都從頭到尾跑一次，下筆慢、中間快、收筆慢；文字從左到右寫出來。
3. **顏色塗到線外面**。色塊故意跟外框錯開七、八個像素，大面積用斜線一條一條塗。
4. **線會抖**。整層套了一個位移濾鏡，每 1/6 秒換一次變形——就是手繪動畫一張一張重畫時的那個抖動。
   字幕不在這一層裡，所以不會抖、好讀。

字型是 macOS 內建的翩翩體（標題、清單）與手札體（字幕）。**在其他作業系統上重新渲染會退回別的字型**，
要換成網路字型的話改 `reel.html` 最上面的 `--hand` 與 `--note`。

## 聲音

- **旁白**：`zh-TW-HsiaoChenNeural`，語速 +5%。
- **配樂**：程式合成，96 BPM、C–G–Am–F，烏克麗麗刷弦＋彈指＋鐘琴；清單劃完那一幕加口哨與拍手。
  第 1 幕是小調、零零落落的撥弦，音愈來愈密。
- **音效**：鉛筆的沙沙聲（每一筆都有）、麥克筆、打勾、翻頁、蓋章。時間點跟畫面同一個來源
  （`reel.html` 裡的 `c.sfx(...)`）。
- **字幕**：已燒進畫面。**上傳時請關掉 IG 的自動字幕**。

## 怎麼重新產出

```
cd build
pip install edge-tts numpy scipy        # 第一次才需要
npm i playwright                        # 第一次才需要

python3 make-vo.py        # 錄旁白，並依旁白長度產生 timeline.json / timeline.js
node    render.js --sfx   # 從 reel.html 讀出音效時間表 → sfx.json
python3 make-bgm.py       # 合成配樂 bgm.wav 與音效 sfx.wav
python3 make-audio.py     # 旁白＋配樂＋音效 → audio.m4a（-14 LUFS）
node    render.js         # 逐幀截圖餵給 ffmpeg → ../avalo-handdrawn-reel.mp4
```

改清單上的項目：`reel.html` 的 `ITEMS`（六項的文字）、對應的 `scene(...)`（塗鴉），
以及 `make-vo.py` 的 `SCENES`（旁白）。

檢查畫面：`node render.js --shots 8.6,22.6,47.9` 會把指定秒數存到 `build/frames/`。
